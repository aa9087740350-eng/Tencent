# TalentLens AI 智能晋升评估助手

TalentLens AI 是一个面向 HR 晋升评审场景的 Streamlit Web App Demo。它的定位不是让 AI 直接决定员工是否晋升，而是帮助 HR 更快识别晋升风险、发现隐性贡献、解释评分原因，并在异常结果出现时触发人工复核。

## 项目背景

企业引入 AI 晋升评估系统后，评审效率可能显著提升，例如评审周期缩短、人力成本下降、流程更加标准化。但如果系统只关注 KPI、培训时长、考试成绩等显性数据，就可能忽视跨部门协作、技术攻关、带教新人、组织影响力等真实贡献，也可能把高绩效执行者误判为高潜管理者。

TalentLens AI 的核心理念是：**AI 辅助 HR 决策，但不替代人工判断**。最终晋升结果应由 AI 数据分析、HR 人工复核和管理者判断共同完成。

## 解决的问题

- 识别高绩效但岗位匹配不足的晋升风险。
- 发现 KPI 之外的隐性贡献和组织影响力。
- 解释员工为什么被推荐、复核或暂缓晋升。
- 将异常评分、高潜未推荐、经理评分差异过大等情况送入人工复核池。
- 通过透明反馈提升员工对晋升制度的公平感和信任感。

## 核心功能

1. **晋升评估总览**  
   展示参与晋升人数、AI 辅助推荐人数、人工复核人数、高风险人岗错配案例、平均公平感评分和预测岗位胜任率，并提供部门推荐比例、风险分布、评分维度均值和 AI / 经理评分差异图表。

2. **员工评估详情**  
   支持选择员工，查看基本信息、多维评分、晋升风险等级、AI 辅助建议、复核触发原因和建议 HR 动作。

3. **隐性贡献识别器**  
   基于关键词规则识别跨部门协作、技术攻关、带教新人、知识分享、冲突处理、组织影响力、危机处理和流程优化等隐性贡献标签。

4. **人工复核池**  
   汇总所有需要人工复核的员工，展示复核触发原因和建议 HR 动作，防止算法误判直接变成晋升结果。

5. **可解释反馈报告**  
   自动生成中文反馈报告，覆盖评估结果、主要优势、当前不足、建议原因、可能被低估的贡献、下一步发展建议和补充材料建议。

## 本地运行方法

进入项目目录：

```bash
cd talentlens-ai
```

安装依赖：

```bash
pip install -r requirements.txt
```

启动应用：

```bash
streamlit run app.py
```

浏览器打开 Streamlit 提示的本地地址，即可体验 Demo。

## 部署到 Streamlit Community Cloud

1. 将 `talentlens-ai` 项目上传到 GitHub 仓库。
2. 登录 [Streamlit Community Cloud](https://streamlit.io/cloud)。
3. 选择 “New app”，连接对应 GitHub 仓库。
4. 设置主文件路径为 `app.py`。
5. 确认依赖文件为 `requirements.txt`。
6. 点击部署，等待构建完成后即可获得公网访问链接。

## 2 分钟中文产品 Demo 汇报稿

大家好，今天演示的是 TalentLens AI 智能晋升评估助手。这个产品面向 HR 晋升评审场景，但我们首先明确一点：AI 不替代 HR，也不做最终晋升裁判。AI 的角色是整理数据、识别风险、解释原因和触发人工复核；HR 和管理者负责复杂判断、证据校准和最终决策。

在首页，我们可以看到本轮晋升评估的整体情况，包括参与人数、AI 辅助推荐晋升人数、需要人工复核人数、高风险人岗错配案例、平均公平感评分和预测岗位胜任率。这里的重点不是直接告诉 HR 谁应该晋升，而是帮助 HR 快速发现风险部门、风险员工和异常案例。

进入员工评估详情后，系统会根据目标岗位进行分层评分。例如技术负责人更关注技术攻关、项目难度和知识分享；团队管理者更关注团队满意度、人才培养和冲突处理；HRBP 更关注员工关系、业务支持和数据分析能力。这样可以避免用同一套标准评价所有岗位。

第三个模块是隐性贡献识别器。HR 或员工可以输入贡献描述，系统会识别跨部门协作、技术攻关、带教新人、知识分享、危机处理和流程优化等标签，帮助发现 KPI 之外的真实组织贡献。

第四个模块是人工复核池。只要出现 AI 总评分和经理评分差异超过 20 分、隐性贡献高但总分偏低、KPI 高但岗位匹配低、管理岗证据不足，或高潜人才未被推荐，系统都会触发人工复核。这样可以防止算法误判直接变成晋升结果。

最后是可解释反馈报告。系统会用更接近 HR 反馈的语气说明员工优势、不足、为什么给出当前建议、哪些贡献可能被低估，以及是否建议提交补充材料或申诉。

TalentLens AI 的最终价值是：效率不牺牲公平，数据不替代人的判断。它让晋升评审更标准化、更透明，也让员工更容易理解和信任晋升机制。

## 产品价值总结

TalentLens AI 通过岗位分层评分、隐性贡献识别、异常结果预警和可解释反馈，把 AI 从“黑箱裁判”变成“HR 评审助手”。它提升评审效率，同时保留人工复核和管理者判断，帮助企业在晋升场景中兼顾效率、公平和组织信任。
